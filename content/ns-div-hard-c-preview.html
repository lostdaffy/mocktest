The number 123...n is formed by writing 1, 2, 3, ..., n one after another (for n = 12 it is 123456789101112). For how many n from 1 to 50 is it divisible by 9?
1, 2, 3, ..., n को एक के बाद एक लिखकर संख्या 123...n बनती है (n = 12 के लिए 123456789101112)। 1 से 50 तक कितने n के लिए यह 9 से विभाज्य है?

  1. 10 ✔
  2. 11
  3. 5
  4. 9

Solution: A number and its digit sum leave the same remainder on division by 9, so the long number leaves the same remainder as 1 + 2 + ... + n = n(n + 1)/2. That is a multiple of 9 when n leaves 0 or 8 on division by 9: n = 8, 9, 17, 18, 26, 27, 35, 36, 44, 45. That is 10 values.
किसी संख्या और उसके अंकों के योग का 9 से शेष समान होता है, अतः लंबी संख्या का शेष 1 + 2 + ... + n = n(n + 1)/2 जैसा। यह 9 का गुणज तब जब n का 9 से शेष 0 या 8: n = 8, 9, 17, 18, 26, 27, 35, 36, 44, 45। कुल 10 मान।

  1. 9 ✔
  2. 18
  3. 27
  4. 36

Solution: n³ + (n + 1)³ + (n + 2)³ = 3n³ + 9n² + 15n + 9 = 3(n³ + 5n) + 9n² + 9, and n³ + 5n is always divisible by 3 (it is n³ − n + 6n). So the sum is a multiple of 9. 1 + 8 + 27 = 36 and 8 + 27 + 64 = 99 have HCF 9, so nothing larger always divides it.
n³ + (n + 1)³ + (n + 2)³ = 3n³ + 9n² + 15n + 9 = 3(n³ + 5n) + 9n² + 9, और n³ + 5n सदा 3 से विभाज्य (यह n³ − n + 6n है)। अतः योग 9 का गुणज। 1 + 8 + 27 = 36 और 8 + 27 + 64 = 99 का HCF 9, अतः इससे बड़ी कोई सदा नहीं।
